# 🤝 Contribuindo / Contributing
## Como Contribuir
1. Fork o repositorio
2. Crie uma branch: `git checkout -b feature/minha-feature`
3. Faca suas alteracoes
4. Envie um Pull Request
## Diretrizes
- Siga o estilo de codigo existente
- Adicione Javadoc em metodos publicos
- Teste localmente antes do PR
- IDs de registro em `snake_case`
- Classe em `PascalCase`
