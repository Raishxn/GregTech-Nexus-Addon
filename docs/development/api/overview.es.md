# :globe_with_meridians: Vista General de la API
La API de GTNA expone Part Abilities y clases de maquinas para desarrolladores de addons.

## Clases Clave
- `GTNAPartAbility` - Abilities personalizados (Thread, Accelerate, Overclock)
- `WorkableElectricMultipleRecipesMachine` - Clase de maquina multi-receta

Ver [Crear Maquinas](machines.md) para ejemplos completos.
