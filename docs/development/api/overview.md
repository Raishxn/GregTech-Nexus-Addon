# 📚 API Overview
O GTNA expoe diversas APIs para addons e scripts KubeJS:
- **IThreadModifierMachine** - Interface para maquinas com suporte a Thread Hatch
- **ParallelMachine** - Interface para maquinas com paralelos customizados
- **GTNAPartAbility** - PartAbilities customizadas (THREAD, ACCELERATE, OVERCLOCK)
- **GTNAMultipleRecipesLogic** - Trait para logica multi-receita
