# :joystick: Integracion KubeJS
> **Estado**: Planeado para v0.2.0

La integracion KubeJS permitira a desarrolladores de modpacks crear maquinas personalizadas usando hatches GTNA sin escribir codigo Java.

## Funciones Planeadas
- Registrar multibloques con tipo `'gtna:multiple_recipes'`
- Acceso a `GTNAPartAbility.THREAD_HATCH`, `ACCELERATE_HATCH`, `OVERCLOCK_HATCH`
- Soporte completo de recetas via eventos KubeJS
- Soporte de hot reload

Ver [PRD #4](../../prd/prd_04_kubejs_compat.md) para la especificacion completa.
