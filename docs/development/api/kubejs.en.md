# :joystick: KubeJS Integration
> **Status**: Planned for v0.2.0

KubeJS integration will allow modpack developers to create custom machines using GTNA hatches without writing Java code.

## Planned Features
- Register multiblocks with `'gtna:multiple_recipes'` type
- Access `GTNAPartAbility.THREAD_HATCH`, `ACCELERATE_HATCH`, `OVERCLOCK_HATCH`
- Full recipe support via KubeJS events
- Hot reload support

See [PRD #4](../../prd/prd_04_kubejs_compat.md) for full specification.
