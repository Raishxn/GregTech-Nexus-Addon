# :factory: Crear Maquinas con Hatches GTNA
Esta guia muestra como crear un multibloque que usa los hatches personalizados de GTNA (Thread, Accelerate, Overclock, Advanced Parallel) y la clase `WorkableElectricMultipleRecipesMachine`.

## Referencia de Part Abilities GTNA
```java
GTNAPartAbility.THREAD_HATCH      // Recetas diferentes simultaneas
GTNAPartAbility.ACCELERATE_HATCH  // Reduce duracion
GTNAPartAbility.OVERCLOCK_HATCH   // Multiplica velocidad
PartAbility.PARALLEL_HATCH        // Advanced Parallel (GT base)
```

Para ejemplos completos con tabs Java/KubeJS, ver la [version en portugues](machines.md) de esta pagina.
