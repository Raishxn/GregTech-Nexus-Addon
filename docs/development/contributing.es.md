# :handshake: Contribuir
## Como Contribuir
1. Haz fork del repositorio
2. Crea una branch: `git checkout -b feature/mi-feature`
3. Haz tus cambios
4. Envia un Pull Request

## Directrices
- Sigue el estilo de codigo existente
- Agrega Javadoc en metodos publicos
- Prueba localmente antes del PR
- IDs de registro en `snake_case`
- Clases en `PascalCase`
