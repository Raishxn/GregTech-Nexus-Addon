# 🪨 Steam Cobbler
> *"Gerando pedra do nada — literalmente."*

## Stats Rapidos
| Propriedade | Valor |
|------------|-------|
| **Tipo** | Multiblocko a Vapor |
| **Tamanho** | 11x6x11 (WxHxD) |
| **Receitas** | Rock Breaker |
| **Paralelos** | 16 |
| **Velocidade** | 1x (padrao) |
| **Consumo** | 1200 L/s Steam |

## Beneficios
- Gera pedra automaticamente sem bloco fonte
- 16 paralelos para producao em massa
- Use Programmed Circuits para selecionar tipo de pedra
- Sem eletricidade necessaria
