# :pick: Void Miner (Steam Gate Aged)
> *`Extrae riquezas del vacio absoluto - alimentado por vapor supercritico.`*

## Stats Rapidos
| Propiedad | Valor |
|-----------|-------|
| **Tipo** | Multibloque de Vapor |
| **Recetas** | Void Miner (configurable) |
| **Velocidad** | Variable por tier de vapor (1x a 5x) |

## Tiers de Fluido de Vapor
| Fluido | Output | Velocidad | Costo Energia |
|--------|:------:|:---------:|:-------------:|
| Vapor Normal | 1x | 1x | 1x |
| Dense Supercritical | **2x** | **2x** | 1.5x |
| SuperHeated | **3x** | **3x** | 2x |
| Insanely Supercritical | **5x** | **5x** | 4x |

!!! tip "Mejor Relacion Costo-Beneficio"
    El **SuperHeated Steam** ofrece la mejor relacion: 3x output y 3x velocidad por solo 2x costo de energia.
