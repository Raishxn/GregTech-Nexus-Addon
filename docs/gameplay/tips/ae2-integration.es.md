# :electric_plug: Integracion AE2

## Consejos con Applied Energistics 2
- Usa **ME Storage Bus** en los Output Buses de GT para importar a la red AE2
- Habilita *Input from output side* con Screwdriver en maquinas GT
- Usa **Blocking Mode** en el ME Interface al alimentar maquinas GT
- **Prioridad -1**: Storage Bus con prioridad -1 consume subproductos antes del almacen principal
- **P2P Fluid Tunnel**: Throughput ilimitado para fluidos
- **Crafting CPU**: Configura autocraft para componentes de uso frecuente
