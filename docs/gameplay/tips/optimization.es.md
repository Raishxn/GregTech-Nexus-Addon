# :bulb: Consejos de Optimizacion

## Consejos Generales
- Usa **Wireless Steam** para eliminar tubos y reducir lag
- **Wall Sharing** funciona entre multibloques GTNA y GT base
- **Huge Steam Buses** tienen mas slots que los buses normales
- Combina **Thread + Accelerate + Overclock** para velocidad maxima
- Empieza con el **Large Steam Alloy Smelter** (multibloque mas facil)

## Eficiencia de Vapor
- El **Large Steam Furnace** consume 50% menos vapor de lo normal
- El **Mega Solar Boiler** provee vapor infinito gratis (requiere luz solar)
- Usa Steel Wireless Hatches para capacidad maxima
