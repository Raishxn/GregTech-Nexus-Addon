# :electric_plug: AE2 Integration

## Tips with Applied Energistics 2
- Use **ME Storage Bus** on GT Output Buses to import into AE2 network
- Enable *Input from output side* with Screwdriver on GT machines
- Use **Blocking Mode** on ME Interface when feeding GT machines
- **Priority -1**: Storage Bus with priority -1 consumes byproducts before main storage
- **P2P Fluid Tunnel**: Unlimited throughput for fluids
- **Crafting CPU**: Set up autocrafting for frequently used components
