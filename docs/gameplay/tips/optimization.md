# 💡 Dicas de Otimizacao / Optimization Tips
## Dicas Gerais
- Use **Wireless Steam** para eliminar tubos
- **Wall Sharing** funciona entre multiblocos GTNA e GT base
- **Huge Steam Buses** tem mais slots que as buses normais
- Combine **Thread + Accelerate + Overclock** para velocidade maxima
