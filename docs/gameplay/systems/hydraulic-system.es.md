# :wrench: Sistema Hidraulico

## Componentes
GTNA agrega 10 componentes hidraulicos:

| Componente | Uso |
|-----------|-----|
| Hydraulic Motor | Mecanismos de accionamiento |
| Hydraulic Piston | Fuerza mecanica |
| Hydraulic Pump | Transferencia de fluidos |
| Hydraulic Arm | Operacion robotica |
| Hydraulic Conveyor | Logistica de items |
| Hydraulic Regulator | Control de presion |
| Hydraulic Vapor Generator | Generacion de vapor |
| Hydraulic Steam Jet Spewer | Salida de chorro de vapor |
| Hydraulic Steam Receiver | Entrada de vapor |
| Precision Steam Component | Manufactura de precision |

Estos componentes se usan en recetas de **Hydraulic Manufacturing** en el Steam Manufacturer.
