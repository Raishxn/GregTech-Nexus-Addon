# 📡 Wireless Steam Network
## Como Funciona
Cada jogador tem sua propria rede wireless de vapor. Usa `SteamNetworkData` (SavedData) para armazenar vapor globalmente.
### Componentes
- **Wireless Steam Output Hatch** - Conecte ao boiler, envia vapor para a rede
- **Wireless Steam Input Hatch** - Conecte a maquina, recebe vapor da rede
### Dicas
- Sem limite de distancia (funciona entre dimensoes!)
- Cada jogador tem rede separada (baseada em UUID)
- Variantes Steel tem capacidade maxima
