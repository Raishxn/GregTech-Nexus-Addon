# :wrench: Hydraulic System

## Components
GTNA adds 10 hydraulic components:

| Component | Use |
|-----------|-----|
| Hydraulic Motor | Drive mechanisms |
| Hydraulic Piston | Mechanical force |
| Hydraulic Pump | Fluid transfer |
| Hydraulic Arm | Robotic operation |
| Hydraulic Conveyor | Item logistics |
| Hydraulic Regulator | Pressure control |
| Hydraulic Vapor Generator | Steam generation |
| Hydraulic Steam Jet Spewer | Steam jet output |
| Hydraulic Steam Receiver | Steam input |
| Precision Steam Component | Precision manufacturing |

These components are used in **Hydraulic Manufacturing** recipes in the Steam Manufacturer.
