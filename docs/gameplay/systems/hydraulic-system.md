# 🔧 Sistema Hidraulico / Hydraulic System
## Componentes
O GTNA adiciona 10 componentes hidraulicos:
- Hydraulic Motor
- Hydraulic Piston
- Hydraulic Pump
- Hydraulic Arm
- Hydraulic Conveyor
- Hydraulic Regulator
- Hydraulic Vapor Generator
- Hydraulic Steam Jet Spewer
- Hydraulic Steam Receiver
- Precision Steam Component
Esses componentes sao usados em receitas do tipo **Hydraulic Manufacturing** no Steam Manufacturer.
