# Hatches y Partes
GTNA agrega 4 tipos de hatch personalizados para multibloques electricos:

| Hatch | Tiers | Funcion |
|-------|:-----:|---------|
| Thread Hatch | ZPM-MAX | Ejecuta recetas diferentes simultaneamente |
| Accelerate Hatch | LV-MAX | Reduce la duracion de recetas |
| Overclock Hatch | UV-MAX | Multiplica velocidad de overclock |
| Advanced Parallel Hatch | UHV-OpV | 1K a 262K paralelos |
