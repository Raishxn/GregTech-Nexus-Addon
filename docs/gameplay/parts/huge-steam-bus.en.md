# :package: Huge Steam Buses
## Input Bus & Output Bus
Expanded versions of Steam Item Buses with more inventory slots.

| Bus | Slots | Tier |
|-----|-------|------|
| Huge Steam Input Bus | Expanded | ULV |
| Huge Steam Output Bus | Expanded | ULV |

Use the standard GT model with custom GTNA overlay. These are essential for multiblocks that need to handle many item types simultaneously.
