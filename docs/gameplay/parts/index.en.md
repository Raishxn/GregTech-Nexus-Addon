# Hatches & Parts
GTNA adds 4 custom hatch types that enhance electric multiblocks:

| Hatch | Tiers | Function |
|-------|:-----:|----------|
| [Thread Hatch](thread-hatch.md) | ZPM-MAX | Run different recipes simultaneously |
| [Accelerate Hatch](accelerate-hatch.md) | LV-MAX | Reduce recipe duration |
| [Overclock Hatch](overclock-hatch.md) | UV-MAX | Multiply overclock speed |
| [Advanced Parallel Hatch](advanced-parallel-hatch.md) | UHV-OpV | 1K to 262K parallels |

Plus steam-specific parts:
- [Wireless Steam Hatches](wireless-steam-hatches.md) — Transmit steam wirelessly
- [Huge Steam Bus](huge-steam-bus.md) — Extended item I/O for steam machines
