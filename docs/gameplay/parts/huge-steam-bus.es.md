# :package: Huge Steam Buses
## Input Bus y Output Bus
Versiones expandidas de los Steam Item Buses con mas slots de inventario.

| Bus | Slots | Tier |
|-----|-------|------|
| Huge Steam Input Bus | Expandido | ULV |
| Huge Steam Output Bus | Expandido | ULV |

Usan el modelo estandar de GT con overlay personalizado de GTNA. Son esenciales para multibloques que necesitan manejar muchos tipos de items simultaneamente.
