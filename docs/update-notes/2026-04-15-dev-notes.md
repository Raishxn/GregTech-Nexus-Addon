# GTNA Update Notes - 2026-04-15

## Added
- Quantum Cosmic Nexus armor set with imported textures, custom armor material, full-set handler, Avaritia-style defensive effects, creative flight, sustain, step assist, knockback immunity, damage reflection, `/kill` protection, and a custom `reality_rip` exception path.
- Reality Ripper sword with custom texture and `reality_rip` damage type that bypasses creative mode and the Quantum Cosmic Nexus armor.
- Custom `reality_rip` damage type and death messages.
- Output boost multiblock parts:
  - output boost hatch
  - output boost item bus
  - output boost fluid hatch
  - steam output boost bus
- Infinite multiblock input parts:
  - infinite input bus
  - infinite input hatch
  - infinite steam input bus
- AE2/Nexus Molecular Forge related integrations and supporting machine pieces introduced in this work batch.

## Buffed
- Output boost progression now scales by tier instead of using a flat multiplier.
- Output boost hatch compatibility was extended so multiblocks that accept the parallel hatch slot can use it as the boost source.
- Mufflers now improve energy efficiency by tier through a single recipe-logic mixin:
  - LV: 0%
  - MV: 2%
  - HV: 4%
  - EV: 6%
  - continues at +2% per tier above MV
- Quantum Cosmic Nexus armor was pushed to endgame/Avaritia-level survivability.

## Changed
- Jade multiple-recipes provider translation generation was fixed so manual tooltip/lang entries are preserved during `runData`.
- Datagen language generation now imports the manual `en_us.json` first, then augments it with generated entries.
- Output boost and no-consume behavior for multiblocks was centralized through mixins/util helpers rather than per-machine hardcoding.

## Removed
- Old Nexus armor set, associated item models, textures, armor classes, and wings layer.

## Pending Follow-Up
- Existing non-fatal client warnings still worth cleaning later:
  - missing dynamic render types for some custom machine models
  - OBJ/material warnings for space model
  - duplicated EMI recipe IDs

## Added After Checkpoint
- Singleblock infinity covers:
  - steam singleblock cover with infinite steam supply
  - electric singleblock cover with infinite power

## Buffed After Checkpoint
- Singleblock cover behavior now:
  - does not consume item or fluid recipe inputs
  - speeds recipes up by 5x
  - multiplies item and fluid outputs by 10x
  - removes the effective power or steam cost from covered singleblock recipe execution
