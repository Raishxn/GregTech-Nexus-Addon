# Instalacion
1. Instala **Minecraft 1.20.1** con Forge 47.x
2. Instala **GregTech CEu Modern** (ultima version)
3. Descarga **GregTech Nexus Addon** de [GitHub Releases](https://github.com/Raishxn/GregTech-Nexus-Addon/releases)
4. Coloca el `.jar` en la carpeta `mods/`
5. Inicia el juego!

## Requisitos
| Mod | Version | Requerido |
|-----|---------|:---------:|
| Minecraft Forge | 47.x | Si |
| GregTech CEu Modern | 7.4.x+ | Si |
| LDLib | Ultima | Si |
| KubeJS (opcional) | 6.x | No |
