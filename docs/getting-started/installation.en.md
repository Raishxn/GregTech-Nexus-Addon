# Installation
1. Install **Minecraft 1.20.1** with Forge 47.x
2. Install **GregTech CEu Modern** (latest version)
3. Download **GregTech Nexus Addon** from [GitHub Releases](https://github.com/Raishxn/GregTech-Nexus-Addon/releases)
4. Place the .jar file in the mods/ folder
5. Launch the game!

## Requirements
| Mod | Version | Required |
|-----|---------|:---:|
| Minecraft Forge | 47.x | Yes |
| GregTech CEu Modern | 7.4.x+ | Yes |
| LDLib | Latest | Yes |
| KubeJS (optional) | 6.x | No |
